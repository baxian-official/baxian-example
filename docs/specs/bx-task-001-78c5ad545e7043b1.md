# 空名字使用默认问候

## 背景

当前 `hello.js` 的 `greet(name)` 直接拼接名字，名字为空字符串时会得到 `Hello, !`。页面清空输入框后提交，也会显示这个不友好的结果。

## 目标

当且仅当名字为空字符串 `''` 时，使用默认问候 `World`。普通名字与中文名字的问候结果保持不变。

## 行为约定

- `greet('')` 返回 `'Hello, World!'`。
- `greet('baxian')` 返回 `'Hello, baxian!'`，`greet('小明')` 返回 `'Hello, 小明!'`。
- 只在 `name === ''` 时替换为 `World`；不增加 `trim`，空白字符串（如 `'   '`）保持现有行为。
- 不增加语言切换或其他新功能，不引入新依赖。

## 页面行为

`index.html` 已通过 `greet(name.value)` 渲染结果，清空名字后提交应显示 `Hello, World!`，无需改动页面逻辑（如实现阶段发现必须改动，需在 PR 中说明）。

## 测试

使用 Node.js 内置 `node:test` 与 `node:assert/strict`：

- 空字符串返回默认问候。
- 普通名字、中文名字的既有用例继续通过。

运行 `npm test` 验证。
